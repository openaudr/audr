# AUDR Spec

This tree holds the **current version only** of the AUDR specification. The
version is declared by the schema's `$id` and the `spec_version` pattern.

Released versions are git tags `spec/vX.Y.Z` and are published at
`https://openaudr.dev/spec/vX.Y.Z/`.

Changes between versions are recorded in [`CHANGELOG.md`](CHANGELOG.md).
